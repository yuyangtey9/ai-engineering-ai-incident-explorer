# Data licences and attribution

## data/processed/prepared_incidents.csv
Derived from the AI Incident Database (https://incidentdatabase.ai), weekly snapshot incidents table.
Licence: CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/), as stated in the snapshot's license file.
Attribution: AI Incident Database. Report text (reports.csv) is not used or included.
Changes made: column names standardised, whitespace trimmed, rows without an ID and exact duplicate rows removed, and a source_url column added. This file is shared under the same licence (CC BY-SA 4.0).

## data/processed/prepared_risks.csv
Derived from the MIT AI Risk Repository (https://airisk.mit.edu), AI Risk Database v4 (updated 03 December 2025).
Licence: CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/), as stated on airisk.mit.edu.
Attribution: Slattery, P., Saeri, A. K., Grundy, E. A. C., Graham, J., Noetel, M., Uuk, R., Dao, J., Pour, S., Casper, S., & Thompson, N. (2024). The AI Risk Repository: A Comprehensive Meta-Review, Database, and Taxonomy of Risks from Artificial Intelligence. arXiv:2408.12622.
Changes made: column names standardised, whitespace trimmed, rows without an ID and exact duplicate rows removed.
